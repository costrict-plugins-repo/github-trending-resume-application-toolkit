Job Application Toolkit

An automated pipeline that produces keyword-optimised resumes and cover letters. Built as a plugin for Claude Code and Cowork.

View on GitHub Get Started

What It Does

Paste a job ad and the toolkit handles the rest. It analyses your positioning, extracts recruiter keywords, generates tailored documents, and verifies everything programmatically before presenting the results.

Every document is built from a single instructions file containing your career history, achievements, and writing style. You fill it in once, then the toolkit tailors it for each application.

Application Tracking

The Keyword Strategy

This is what sets the toolkit apart from generic resume builders. Instead of stuffing keywords or ignoring them, it uses a deliberate placement methodology refined across 160+ real job applications.

The Core Rule

Every recruiter keyword is extracted from the job ad, categorised, and assigned to exactly one location across the resume and cover letter. Each distinctive phrase appears no more than twice across both documents combined. The result: documents that pass ATS keyword scans while reading naturally to human recruiters.

Four-Category Extraction

Keywords are sorted into Role-Specific Phrases, Domain/Technical Terms, Capability/Competency Phrases, and Seniority Markers.

Placement Mapping

Each phrase is assigned to a specific section in either the resume or cover letter, ensuring natural distribution.

Programmatic Verification

After generation, a verification script checks placement accuracy, word count, and cross-document repetition.

Getting Started

The toolkit works with Claude Code (CLI) and Cowork (desktop app).

Option 1: Clone and run

# Clone the repo
git clone https://github.com/michaelzajer/job-application-toolkit.git

# Run Claude Code with the plugin loaded
claude --plugin-dir ./job-application-toolkit

Option 2: Install in Cowork

Download the .plugin file from the releases page and install it through the Cowork desktop app.

First-time setup

Once loaded, say "help me set up my job application instructions" and the toolkit will walk you through creating your personal instructions file with your career history, achievements, and writing style.

After that, paste any job ad and say "new application" to generate tailored documents.
